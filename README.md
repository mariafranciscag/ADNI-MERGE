## Overview
Alzheimer's disease (AD) is the most common cause of dementia, and its early diagnosis remains difficult. Biomarker-based predictive models can support diagnosis, but clinical adoption requires **interpretable** models rather than black boxes.

**SLIM-GSGP** (Vanneschi et al., 2026) is a Geometric Semantic Genetic Programming variant that uses inflate/deflate mutations to control bloat, producing small, interpretable symbolic models. However, it currently supports only regression (plus a binary adaptation from GSGP), leaving **multiclass classification** unaddressed.

This repository contains the code for the first multiclass extensions of SLIM-GSGP, evaluated on the three-class diagnostic task from **ADNIMERGE**:

| Class | Description |
|-------|-------------|
| CN | Cognitively Normal |
| MCI | Mild Cognitive Impairment |
| Dementia | Dementia |

## Research Question

> How can SLIM-GSGP be extended to multiclass classification, and how do alternative extension strategies compare in predictive performance and model interpretability when applied to Alzheimer's disease diagnosis?

## Objectives
1. Analyse the limitations of SLIM-GSGP for multiclass problems.
2. Design and implement a native multiclass SLIM-GSGP extension.
3. Design and implement M3GP (Muñoz et al., 2015) applied to SLIM.
4. Evaluate and compare both extensions on ADNIMERGE in terms of predictive performance and model size (number of nodes, as a proxy for interpretability), with statistical tests over independent runs.
5. Identify the most predictive demographic, genetic, imaging-derived and CSF biomarkers, validating them against the literature and with a domain expert.

## Approaches
| Approach | Idea |
|----------|------|
| **Native SLIM-GSGP extension** | A single individual holds one tree per class (tree/bit-based formulation). |
| **SLIM-M3GP** | Multi-tree individuals map the data into a new feature space, where classification is distance-based (M3GP-inspired multidimensional formulation). |
